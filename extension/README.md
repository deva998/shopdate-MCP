# 共用 Chrome 数据桥

本目录是京东商智、生意参谋和万相台共用的唯一插件目录，不属于某一个业务平台。`components/jd/tb` 与 `components/ali/tb` 是两套独立业务程序，仍需保留。

## 首次安装

1. 先按项目根目录README运行安装脚本。
2. 在Chrome打开 `chrome://extensions`，开启开发者模式，点击“加载已解压的扩展程序”，选择安装器 `CHROME_EXTENSION` 输出的目录，即本目录。
3. 保持目录固定，在同一Chrome登录需要使用的后台，再通过对应shopdate MCP调用 `doctor` 检查连接。

本目录直接包含 `manifest.json`，不再需要进入 `unpacked` 子目录；不要点击“打包扩展程序”。`bridge-config.json` 只包含公开插件身份和连接配置，不是账号或登录态。

## 从旧版升级

v1.2.0只调整打包位置，插件仍为0.9.62，公开公钥和扩展ID保持不变，插件程序文件与旧版逐字节相同。

- **已有插件运行正常：推荐将新版ZIP解压到新目录安装，继续保留原目录和现有插件。** 新MCP按相同扩展ID连接，不要求立即迁移Chrome的加载路径；两侧doctor通过即可。不要删除、移动正在使用的旧目录，也不要为迁移路径直接卸载插件，以免影响插件保存的账号状态。
- 若Chrome正在加载旧仓库内的插件，**不要直接原地git pull升级**：本次目录调整会移除旧路径。先采用新目录ZIP安装方式，保持旧的实际加载路径有效；此说明不代表已验证Chrome存储迁移。
- 新安装者加载本目录。已有用户如要改用新路径，应先确认插件内账号状态有可恢复安排，再在本人Chrome中处理；本版未实测Chrome更改加载路径后的存储迁移，不承诺卸载重装能保留账号。
- 只有插件版本低于所需版本时才需更新对应插件代码。保留 `manifest.json` 中的公开公钥，不自行生成新ID，不导出或分享登录态。

本次验证覆盖旧的现有0.9.62插件与新布局MCP互通；没有自动修改Chrome配置、加载新插件或重新登录。安装及客户端说明见根目录README。
