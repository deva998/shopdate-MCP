# 共用 Chrome 数据桥

本目录是京东商智、生意参谋和万相台共用的唯一插件目录，不属于某一个业务平台。`components/jd/tb` 与 `components/ali/tb` 是两套独立业务程序，仍需保留。

## 首次安装

1. 先按项目根目录README运行安装脚本。
2. 在Chrome打开 `chrome://extensions`，开启开发者模式，点击“加载已解压的扩展程序”，选择安装器 `CHROME_EXTENSION` 输出的目录，即本目录。
3. 保持目录固定，在同一Chrome登录需要使用的后台，再通过对应shopdate MCP调用 `doctor` 检查连接。

本目录直接包含 `manifest.json`，不再需要进入 `unpacked` 子目录；不要点击“打包扩展程序”。`bridge-config.json` 只包含公开插件身份和连接配置，不是账号或登录态。

## 从旧版升级

当前数据桥为 **0.9.67**，新增CPS付款／佣金／趋势及完整周、月和自定义区间读取。公钥和扩展ID保持不变，插件权限及账号存储代码未改变；旧0.9.62插件不能提供本批新增CPS能力。

- 新版ZIP解压到新目录安装；若Chrome已加载旧插件，先保留该原目录和现有账号状态，不直接卸载或更改Chrome加载路径。
- 需要使用新增CPS字段时，可先备份原插件程序文件，再将新版extension目录内文件更新到原加载目录（不删除旧目录、不修改公钥），在chrome://extensions点击该扩展的重新加载，然后通过shopdate-jd MCP检查连接及命令支持。
- 本工具不自动替用户覆盖插件、修改Chrome配置或迁移账号存储。本轮没有执行用户Chrome中的代码更新或存储迁移，不承诺卸载重装能保留账号。
- Chrome正在加载旧仓库内插件时，不要直接原地git pull目录改版；按上面的新目录安装与原路径更新方式处理。不要导出或分享登录态。

完整安装、下载校验及验证边界见根README和docs/VALIDATION.md。新版CPS字段仍需本人后台权限；遇到安全验证停止重试，由用户手动处理。
