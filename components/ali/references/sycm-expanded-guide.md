# 生意参谋新增业务接口与字段口径

适用于 v1.1.0。先通过 shopdate-symc 的 commands 查看参数，再调用 run，platform=sycm。数据只经对应 MCP 获取；未授权、风控、缺失字段、空结果和未完成分页均须保留，不切换其他通道补取。

## 销售、退款、营销与视频

business-catalog 列出固定报表与周期，business-query 的 --report 选择报表。销售概览、明细、趋势及终端／类目／价格带／品牌构成使用官方 payAmt、payByrCnt、payItmCnt 等字段，区分金额、人数、件数，不能按名称推测单位。同行字典只控制对比对象，不筛选本店销售。

营销工具与玩法支持已声明的概览、趋势、活动、商品及部分 SKU 下钻；周期和筛选按报表逐项校验。实时概况及行业排名是当前快照，不接受历史日期冒充历史数据。来源树保留父子层级，人数不可直接相加。

refund-close-overview 使用原付款日期口径；refund-close-trend 是逐日查询所得的支付队列序列，不是独立退款发生日趋势。退款原因、退款成功和退货不是同一口径，不据此推算真实退货率。

video-overview 是全店视频概览，video-trend 是官方近30日趋势；video-list 是商品聚合列表，不是单条视频素材清单，也不能把一页求和当全店总量。列表保留实际行数、总记录数和 complete 标记。

## 客户、内容、服务和业务专区

module-catalog 列出已登记的客户、内容、服务、市场活动及业务专区定义；module-query --report 只运行固定只读契约。保留官方 indexCodes、字段单位、空值与比较对象。注册了接口不等于所有账号和筛选均可用，首屏结果不代表全量。

## 市场榜单、趋势、搜索、类目和竞争

market-query 支持已登记的官方类目、价格选项、商品／店铺榜、搜索及类目洞察。自然周／月必须完整；只用官方选项，不猜类目或属性 ID，不将指数和区间换算为精确销售额。

market-lane 先读取官方更新日、类目与同日 filters，再按 --type、--tag、--price 选择趋势榜单。包内选项标有采集日期，只是种子字典；更新日变化后应重新读取。缺失 tag_rk 的官方选项保留名称，不能编造 ID。seller-items 需要同日、同类目、同标签排名证据，且原生接口未声明价格筛选或分页时不开放这些参数。

market-deep 支持固定的搜索／类目下钻和监控列表读取；竞店／竞品必须来自原生选项或同周期监控证据，不能猜或解密标识，也不新增关注／配置。跨周期聚合、日期回显与原生趋势轴分别标记，不把请求日期当响应已核实日期。

market-observe 仅被动诊断已打开的官方页面请求，有限时与脱敏保护，不操作页面、不修改请求；market-recruit-source 只读取固定官方入口结构，不能把 HTML 或声明发现写成统计数据已接入。

## 固定协议与缺口

protocol-query 提供有限的 MTOP 统计和 QuickBI 元信息／固定服饰确收统计。签名及授权上下文留在浏览器内部；元信息、报表定义、全零样本和有效统计分别标记。服饰确收固定日期规则为官方默认前两天，不支持任意 SQL 或字段。

公共静态资源发现仅返回文本声明，不执行下载的脚本。风控时停止重试，用户完成验证后再查询。包内不包含本地在线验收明细、账号经营响应或报表模板，catalog 未附验收记录不表示接口不存在；本轮离线回归及协议验证范围见 docs/VALIDATION.md。
