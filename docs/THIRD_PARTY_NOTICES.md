# 发布改动

Python 第三方库通过 requirements.txt 安装，不随源码包携带已安装环境。其许可证由各自发行包提供。Chrome 数据桥 manifest 中的公开公钥用于固定扩展 ID，不是登录凭据或私钥。

SOURCE_PROVENANCE.json 列出所收录源文件的输入哈希与发布副本改动；根目录 SHA256SUMS.json 是最终交付文件哈希。公开接口路径、参数契约和公开脚本来源哈希不属于店铺响应数据。

发布改动仅涉及组件相对定位、模块边界、MCP取数规则、匹配数据桥、安装配置、文档和移除店铺特定证据位置。没有携带账号缓存、原始店铺响应、历史报表或开发者客户端配置。未纳入广告关停等私人写操作模块。
