# 仓库文件用途

普通使用者主要看[首页](../README.md)、[功能清单](../功能清单.md)和[Agent安装教程](../AGENT_INSTALL.md)。其余文件承担运行、维护或来源说明职责，不能按文件名随意删除。

| 文件或目录 | 用途 | 是否保留 |
|---|---|---|
| README.md | 安装、功能入口、流程图、常见问题 | 保留在首页 |
| 功能清单.md | 京东/阿里业务作用、命令映射与明确缺口 | 保留在首页，已合并原FEATURES.md |
| AGENT_INSTALL.md | Agent一句话安装及安全合并配置步骤 | 保留在首页，安装提示词依赖它 |
| install.ps1 / install.sh | Windows/macOS安装入口 | 必需 |
| installer.py / requirements.txt | 创建环境、安装依赖、生成MCP配置 | 必需 |
| shopdate.py | 公共启动器，隔离京东与阿里两个源码进程 | 必需 |
| components/ | 业务源码、字段契约、指南和Chrome插件 | 必需，不是可丢弃的安装缓存 |
| scripts/ | 配置合并、协议检查、文件审计和打包 | 保留，教程和安装维护使用 |
| mcp-configs/examples/ | 各Agent和系统的配置示例 | 保留，示例路径不能直接运行 |
| tests/ | 安装与配置回归测试 | 运行时不加载，开发维护保留 |
| LICENSE | 原MIT版权及许可 | 必须保留，不能因首页精简删除 |
| AGENTS.md | 约束AI只通过MCP取数、保留缺口、用户手动处理安全验证 | 建议保留，AI工具会读取 |
| .gitignore | 防止误提交虚拟环境、缓存、日志等 | 保留；不能替代隐私检查 |
| .gitattributes | 保持跨系统文件字节和脚本换行，避免哈希变化 | 保留 |
| SHA256SUMS.json | 最终源码文件完整性清单，审计脚本使用 | 保留；修改文件后需更新，不是作者签名 |
| docs/CHANGELOG.md | 版本变化记录 | 非运行依赖，移入维护文档 |
| docs/VALIDATION.md | 实测范围、客户端与Mac缺口 | 非运行依赖，但保留以避免过度宣传 |
| docs/SOURCE_PROVENANCE.json | 收录源码的输入哈希和本地定制说明 | 非运行依赖，维护和追溯保留 |
| docs/THIRD_PARTY_NOTICES.md | 上游来源、版权及第三方说明 | 非运行依赖，许可说明保留 |

`.venv`、`.local`、账号缓存、业务原文、历史报表、真实客户端配置和日志属于本机运行资料，不应上传。Git维护元数据也不收入发行ZIP。
